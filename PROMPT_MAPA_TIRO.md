# Mapa de tiro y parciales por cuarto
La captura FBM identifica equipo superior = mitad izquierda y primer número de cada cuarto; inferior = mitad derecha y segundo número. Cruza cabecera, color y lista; si discrepan, `checksAgree:false`. Responde solo JSON con `quarters` (cuya suma debe coincidir con el marcador), `ownShots`, `opponentShots`, coordenadas 0–1 y canasta arriba. No inventes tiros.
