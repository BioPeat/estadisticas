ESTADÍSTICAS v12

Conectar equipos privados

Este asistente no configura tokens ni toca tus datos. Solo crea el archivo público config.js con la dirección del Worker v12 para que cualquier persona pueda crear su propio equipo privado.

1. Pega la dirección del Worker

La dirección no es una contraseña. No pegues aquí ningún token ni enlace de administrador.

2. Publica un solo archivo

  1. Descarga config.js.
  2. Sustituye en GitHub el config.js de la raíz.
  3. Pulsa Commit changes.
  4. No cambies ni borres assets/.
Buen Consejo sigue funcionando aunque no hagas esto.
La v12 conserva su almacenamiento, token, enlaces y rutas v2. Este paso solo activa la creación automática de equipos nuevos.
