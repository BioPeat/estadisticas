ESTADÍSTICAS v12.3

Conectar equipos privados

Este asistente no configura tokens ni toca tus datos. Publica el Worker v12.3 y crea el archivo público config.js.

1. Cloudflare: copiar, pegar, Deploy

  1. Copia todo 5_CLOUDFLARE/worker.js.
  2. Pégalo en el Worker actual.
  3. Pulsa Deploy.
  4. Abre TU_WORKER/health y comprueba w5-v12.3.

No borres D1, no cambies el binding DB y no abras /api/setup.

2. Pega la dirección del Worker

La dirección no es una contraseña. No pegues aquí ningún token ni enlace de administrador.

3. Publica un solo archivo

  1. Descarga config.js.
  2. Sustituye en GitHub el config.js de la raíz.
  3. Pulsa Commit changes.
  4. No cambies ni borres assets/.
Buen Consejo sigue funcionando aunque no hagas esto.
