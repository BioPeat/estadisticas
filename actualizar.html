Hazla antes de sustituir archivos o publicar una versión.

1Preparar un archivo enfocado

Adjunta ese TXT a un chat nuevo de tu Gem o proyecto de Claude. No subas toda la app.

2Pegar la respuesta

Todavía no se ha comprobado nada.

3Descargar y publicar

Si la comprobación sale verde, descarga el archivo, reemplázalo en el repositorio y usa GitHub Desktop: Commit to main → Push origin.

Después abre la app en una ventana privada y ejecuta python tools/validate.py y python tests/smoke.py si cambiaste lógica o diseño.
