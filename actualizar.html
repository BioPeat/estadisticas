Actualizar toda la app

Esta página trabaja con la copia actual del repositorio, genera contexto íntegro, une respuestas grandes por partes y prepara un ZIP listo para GitHub. Nunca lee ni modifica assets/.

Regla principalGemini o Claude no deben confiar en conocimiento antiguo. En cada petición reciben el contexto recién generado aquí, con todos los archivos de texto completos, longitudes y comprobaciones.
SOLO UNA VEZ

Crear el Gem o Proyecto

Configura las instrucciones de 2_GEMINI o 3_CLAUDE y sube solo su archivo estable. No subas el código como conocimiento permanente: quedaría antiguo.

EN CADA ACTUALIZACIÓN

1. Carga el repositorio actual

Carpeta completa o ZIP recién descargado.

2. Genera contexto

Adjunta el MD; si crece demasiado, se descarga un ZIP de partes completas.

3. Pega la respuesta

Una respuesta normal o varias partes numeradas. También admite archivos completos.

4. Publica y repite

Sube el ZIP a GitHub. La actualización incluye el contexto siguiente regenerado.

1Carga la versión actual

Se incluyen código, pruebas, herramientas, workflow y documentación. Se excluyen assets, capturas, PDF, ZIP, cachés y copias privadas.

Todavía no hay código cargado.

2Pega la respuesta de la IA

Para un cambio normal, pega un JSON y pasa al paso 3. Para una respuesta larga, pega cada parte y pulsa Guardar esta parte; el actualizador comprobará que estén todas.

Admite: changes exactos, sustitución completa con content, archivos nuevos con content y borrado con delete:true. Para borrar se genera un archivo .BORRAR.txt. Nunca se acepta una ruta dentro de assets.

3Comprueba y descarga

Carga el código actual y pega el JSON o guarda sus partes.

Sin bloqueos de versión.
La IA puede subir APP_VERSION, la caché, los recursos versionados y CHANGELOG en la misma actualización. El ZIP incluye el contexto completo posterior al cambio. Conserva assets en GitHub.
