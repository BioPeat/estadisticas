Actualizar la app

La IA no conoce por sí sola qué hay ahora en GitHub. Esta página crea un único archivo de contexto con el código actual, aplica la respuesta multiarchivo y prepara el ZIP para publicar.

Qué sabe Gemini o ClaudeSolo lo que está en sus instrucciones, en sus archivos de conocimiento y en los adjuntos del chat actual. Este flujo no afirma que lean GitHub automáticamente.
SOLO UNA VEZ

Crear el Gem o Proyecto

Pega las instrucciones incluidas en las carpetas 2_GEMINI o 3_CLAUDE. Sube al conocimiento solo el archivo estable GEM_GEMINI.md o PROYECTO_CLAUDE.md de esta entrega. No subas el código, datos, ZIP ni PROYECTO_ESTADISTICAS.md al conocimiento: quedarían antiguos. Esas instrucciones estables se configuran una sola vez.

EN CADA ACTUALIZACIÓN

1. Código actual

Usa la carpeta que acabas de publicar o descarga el ZIP actual de GitHub.

2. Un solo adjunto

Genera CONTEXTO_ACTUAL_ESTADISTICAS.md y adjúntalo en el chat junto con tu petición. Ese archivo sustituye al código antiguo solo para esa conversación.

3. Una respuesta

La IA devuelve solo un JSON multiarchivo.

4. Publicar

Pega el JSON aquí, descarga el ZIP y sube únicamente su contenido a GitHub.

1Carga la versión actual

Elige la carpeta raíz o el ZIP descargado de GitHub. No se sube nada a Internet.

Todavía no hay código cargado.

2Pide el cambio

Adjunta CONTEXTO_ACTUAL_ESTADISTICAS.md en un chat nuevo de tu Gem o Proyecto y escribe la petición con tus palabras. Pega aquí el JSON que responda.

Admite varios archivos, archivos nuevos con content y borrados explícitos con delete:true. Cada búsqueda debe ser literal y única.

3Comprueba y descarga

Carga el código actual y pega el JSON.

La carpeta assets no se borra.
El ZIP contiene solo archivos cambiados, instrucciones de publicación y el contexto maestro actualizado. No elimines archivos de GitHub que no aparezcan en el ZIP.
